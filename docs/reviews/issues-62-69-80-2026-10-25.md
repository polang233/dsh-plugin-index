## 需要知道的限制

- 会话镜像默认读取 ~/.dsh/sessions，目的地默认 E:\DshChatBackup；介绍已提醒配置可用目录。声明 BSD-3-Clause，发布包未带 LICENSE 文件，当前公开仓库有简写许可声明与标准全文链接。
- Doc Review 需要 DSH >=0.2.1-rc.3，记录在浏览器本地，模型审阅会消耗 token。
- Matrix 和 Quick Backup 使用固定 Git 提交。Quick Backup 仅适用于 Windows，需要 PowerShell、Git for Windows 和独立备份仓库初始化；凭据默认不备份，恢复仍通过外部命令执行。
- #69 修正版使用当前会话的 remote.skills.list，原个人清单与固定扫描路径已移除。检查了 npm 包实际函数的读取与刷新行为。公开仓库版本暂为 1.1.2，npm 1.1.3 的刷新订阅差异已核对。
- Synapse 0.5.4 运行文件与固定公开源码一致，更新版本、SHA-512 和源码核查记录。
