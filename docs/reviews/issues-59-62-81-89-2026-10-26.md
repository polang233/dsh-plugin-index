## 暂缓原因

- #59 / @lifenrir/dsh-video-preview：npm 0.1.1 与既有运行代码一致，但 ReadableStream.start 无视 backpressure，持续排入整个请求范围；慢客户端仍可能使大视频常驻内存。暂不迁移，现有 Git 版也有此问题。
- #62 / @gulagala001/dsh-persona-plugin：Git 归档仍缺 exports["./client"] 指向的 lib/client.js，保留已审旧版 0.1.0-dsh.0.2.1-rc.2。
- #62 / @gulagala001/dsh-theme-plugin：Git 归档仍缺 exports["./client"] 指向的 lib/client.js；另确认 Windows 归档解包的路径包含关系检查有缺陷。旧配置不变，线上仍被客户端校验排除。
- #81 / dsh-decision-engine：授权软缓存只按工具、命令族和风险词标记复用低风险分数，不能区分不同代码、目标或会话。enforce 时会跳过本次附加风险判断；宿主原生检查仍在，不声称无条件执行绕过。暂不替换旧包。
- #83 / dsh-qq-gateway：默认空 token 的独立 WebSocket 未认证对端且不校验 Origin；最新连接可接收动作/回复。另有认证前 URL 解析异常未捕获、接收帧/分片无大小上限。暂缓收录。
- #84 / dsh-subagent-dsh：AbortSignal.timeout 被直接作为 Promise.race 元素，会立即完成等待，不能实现启动握手超时/失败回收。静态确认功能问题，未宣称安全漏洞。
- #86 / dsh-bili-mini：Cookie-bearing 请求目的地与重定向限制有效，但原始 webServer 接口的继承鉴权/跨站策略在可用源码中未得到证明；登录轮询未绑定本机发起的二维码。需补充控制证据或修复后再收录，不指认为已确认 CSRF/隐私泄漏。
