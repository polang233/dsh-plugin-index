最简单使用教程

  1. 1开启市场

  2. 2添加索引源

  3. 3粘贴地址

1在终端输入一行命令：

$ dsh plugin --profile desktop add dsh-open-market

2或者在 DSH「插件 → 添加插件」里输入包名dsh-open-market

两种方式都会自动打开「自定义插件市场」、加入本索引，并在「插件」页多出「开放市场」标签，重启 DSH 后生效。

在 DSH 里的样子

不唯 star 🌟 论。默认推荐每天更新，以最近增长快、更新勤、优质的插件为主，同时参考验证、下载量和 star。

  • 同一作者不会霸榜，小开发者的新作品也能上首屏
  • 增长快、更新勤、经过验证等标签一眼可见
  • 默认排序、✨ 智能推荐和随机，每次都有新发现

常见问题

DSH 插件在哪里找？

DeepSeek Harness（DSH）的「发现」页可以添加插件索引源。开放插件市场收录了 854 个社区插件，把 https://dshopen.org/index.json 添加为索引源后，就能在 DSH 里直接浏览、搜索和安装；也可以在本站按分类、增长和更新时间浏览。

DSH 插件怎么安装？

方法一：在「插件 → 实验性插件」中打开「自定义插件市场」，再到「发现 → 添加索引源」粘贴索引地址，然后在「发现」里搜索插件名并安装。方法二：运行 dsh plugin --profile desktop add dsh-open-market，它会自动完成上面的设置，并在「插件」页加一个「开放市场」标签。

插件推荐是怎么排的？

默认推荐每天更新，以最近增长快、更新勤的插件为主，同时参考验证、下载量、star 和点赞。同一作者不会霸榜，新项目和小开发者的作品也有机会上首屏。

和 DeepSeek 官方是什么关系？

开放插件市场是独立的社区项目，与 DeepSeek 官方无隶属关系。它使用 DSH 官方插件市场支持的索引格式，插件由 DSH 自己下载和安装。

怎么把自己的插件提交到 DSH 插件市场？

在 GitHub 上填写收录申请，提供公开源码、npm 包和许可证即可。收录后可以在 README 放上徽章，显示点赞数并链接到本站的插件页。

提交插件的包名或仓库地址，申请收录。
