最簡單使用教程

  1. 1開啟市場

  2. 2新增索引源

  3. 3貼上地址

1在終端輸入一行命令：

$ dsh plugin --profile desktop add dsh-open-market

2或者在 DSH「插件 → 添加插件」裡輸入包名dsh-open-market

兩種方式都會自動開啟「自定义插件市场」、加入本索引，並在「插件」頁多出「開放市場」標籤，重啟 DSH 後生效。

常見問題

DSH 外掛在哪裡找？

DeepSeek Harness（DSH）的「发现」頁可以新增外掛索引源。開放外掛市場收錄了 854 個社群外掛，把 https://dshopen.org/index.json 新增為索引源後，就能在 DSH 裡直接瀏覽、搜尋和安裝；也可以在本站按分類、增長和更新時間瀏覽。

DSH 外掛怎麼安裝？

方法一：在「插件 → 实验性插件」中開啟「自定义插件市场」，再到「发现 → 添加索引源」貼上索引地址，然後在「发现」裡搜尋外掛名並安裝。方法二：執行 dsh plugin --profile desktop add dsh-open-market，它會自動完成上面的設定，並在「插件」頁加一個「開放市場」標籤。

外掛推薦是怎麼排的？

預設推薦每天更新，以最近增長快、更新勤的外掛為主，同時參考驗證、下載量、star 和點贊。同一作者不會霸榜，新專案和小開發者的作品也有機會上首屏。

和 DeepSeek 官方是什麼關係？

開放外掛市場是獨立的社群專案，與 DeepSeek 官方無隸屬關係。它使用 DSH 官方外掛市場支援的索引格式，外掛由 DSH 自己下載和安裝。

怎麼把自己的外掛提交到 DSH 外掛市場？

在 GitHub 上填寫收錄申請，提供公開原始碼、npm 包和許可證即可。收錄後可以在 README 放上徽章，顯示點贊數並連結到本站的外掛頁。
