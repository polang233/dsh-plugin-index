    How this is counted

    A load is one fetch of index.json. People are distinct IP address and user agent pairs within one UTC day: the pair is hashed with a daily salt to dedupe the day and is never stored. Countries and regions come from Cloudflare’s network location as two-letter codes: the split by loads is read from Cloudflare’s own traffic analytics for the last 30 days, and nothing finer than the country is kept. Checks made by this project are not counted.
